# MUDSync

武蔵野大学データサイエンス学部向けのGPUサーバー連携CLIツール。ローカル環境とリモート環境のファイル同期や、Dockerコンテナでのコマンド実行をサポートします。

> [!WARNING]
> 本ツールはサーバー操作を完全に置き換えるものではありません。細かい操作が必要な場合は、従来通りサーバーに直接入る必要があります。特に、サーバーの使用を停止する場合は、必ずサーバーに入り、DockerコンテナとGPUが完全に停止していることを確認してください。

## 準備

下記コマンドを実行し、本ツールをインストールしてください。

```
# pip
pip install git+https://github.com/misya11p/mudsync.git

# uv
uv tool install git+https://github.com/misya11p/mudsync.git
```

下記コマンドを実行し、サーバー情報のデフォルト値を設定してください。

```
msync default
```

- SSH Host: 接続するGPUサーバー。サーバーの情報は事前に`~/.ssh/config`に書いておいてください。
- Remote Path: GPUサーバー上の自分用のホームディレクトリ。例: `/home/musashino-lab/takahashi`
- Data Directory Path: GPUサーバー上のデータディレクトリ。例: `/raid/data/musashino-lab/takahashi`

> [!NOTE]
> コマンド名からも分かる通り、ここで設定した値はあくまでデフォルト値です。プロジェクトごとの設定はどのみち必須であり、ここで設定しておくとそのときに楽ってだけです。

## 使い方

### 初期設定

プロジェクトルートで以下のコマンドを実行し、設定を行います。

```
msync set
```

先ほど設定した3つの項目を改めて設定します。2つのPathには、先で設定したデフォルト値に現在のディレクトリ名が付加されたものが初期値として入ります。設定が完了すると`msync.json`がプロジェクトルートに配置されます。設定の変更を行う場合は、`msync set`を再度実行するか、`msync.json`を直接編集してください。

### ファイル同期

以下のコマンドを実行し、サーバーと同期するファイルを設定します。

```
msync manage
```

上下矢印キーでファイルを選択し、スペースキーで選択状態を切り替えます。ディレクトリを移動したい場合は左右矢印キーを使用してください。データディレクトリにファイルを置きたい場合は`d`キーを押してください。この設定を行ったファイルは実体がデータディレクトリに置かれ、通常のディレクトリにはシンボリックリンクが配置されます。サーバーのストレージを圧迫しないために、大きなファイルはデータディレクトリに置くことを心がけましょう。

同期するファイルを設定したら、以下のコマンドで同期を行います。

```
msync sync
```

### コマンド実行

以下のコマンドで、GPUサーバー上にDockerイメージをビルドします。

```
msync build
```

ビルドは`docker compose build`によって行われます。`compose.yaml`などの設定ファイルを事前に作成し、同期しておいてください。その他オプションはhelpを参照してください。

ビルドが完了したら、以下のコマンドでコンテナを起動します。

```
msync run
```

設定ファイルに記述されたコマンドがコンテナ内で実行されます。コマンド実行は`docker compose run`によって行われます。

また、引数にコマンドを直接指定することもできます。

```
msync run python train.py --epochs 10
```

この場合、`python train.py --epochs 10`がコンテナ内で実行されます。実際の`docker compose run`と同様、最初に見つかった位置引数以降が全てコンテナに渡されます。

その他オプションはhelpを参照してください。

### その他

- `msync info`: 設定した情報を表示します。
- `msync connect`: 指定したGPUサーバーのプロジェクトディレクトリにSSH接続します。
- `msync push`: ローカルからサーバーへ個別にファイルを転送します。
- `msync pull`: サーバーからローカルへ個別にファイルを転送します。

## チュートリアル

実際に手を動かしながら使い方を学んでみましょう。

まずは上記コマンドに従ってインストールとデフォルト値の設定を行ってください。その後、リポジトリをクローンし、専用のディレクトリに移動してください。

```
git clone https://github.com/misya11p/mudsync.git
cd mudsync/tutorial
```

最低限必要なファイルが用意されています。適当に見てみてください。

- `Dockerfile`: 実行環境の定義
- `requirements.txt`: Pythonの依存関係
- `compose.yaml`: コンテナを起動するための設定
- `train.py`: コンテナ内で実行する学習コマンド
- `dummy.txt`: 同期しないファイルの例

次に、プロジェクトの初期設定を行います。

```
msync set
```

`msync.json`が生成されたことを確認してください。

同期するファイルを設定します。`dummy.txt`の選択を外し、Enterキーを押して完了してください。

```
msync manage
```

ファイルを同期します。

```
msync sync
```

Dockerイメージをビルドします。

```
msync build
```

コンテナを起動し、コマンドを実行します。

```
msync run
```

`train.py`が実行され、モデルが学習されるはずです。

最後に、学習させたモデルをローカルに転送します。以下のコマンドを実行してください。

```
msync pull model.pth
```

ローカルに`model.pth`がダウンロードされたことを確認してください。

以上で終了です。チュートリアルで使用したイメージ（`pytorch/pytorch:2.11.0-cuda12.8-cudnn9-devel`）は不要だと思うのでサーバーに入って削除しておいてください。
